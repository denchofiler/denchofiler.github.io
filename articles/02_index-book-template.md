電子帳簿保存法の対応というと「ファイル名に日付・金額・取引先を入れる」という話ばかり目にします。
ですが国税庁は、**索引簿による方法も認めています。**

そして実務では、**索引簿方式のほうが向いている場面が少なくありません。** この記事では、索引簿とは何か、何を書けばいいのか、どう作るのかを具体的に説明します。

---

## 索引簿とは何か

ひとことで言えば、**保存したファイルの一覧表**です。

ファイル名は連番のままにしておき、

```
0001.pdf
0002.pdf
0003.pdf
```

別途、こういう表を作って同じ場所に保存します。

| 連番 | 取引年月日 | 取引金額 | 取引先 | ファイル名 |
|---|---|---|---|---|
| 1 | 2026-01-15 | 1234567 | テスト工業株式会社 | 0001.pdf |
| 2 | 2026-02-03 | 330000 | 株式会社ブルーオーシャン | 0002.pdf |
| 3 | 2026-03-02 | 262900 | 株式会社オフィスサプライ北関東 | 0003.pdf |

これで検索要件を満たせます。ファイル名を1件ずつ書き換える必要はありません。

---

## なぜ索引簿のほうが有利なことがあるのか

検索要件は3つあります。

1. **取引年月日・取引金額・取引先**で検索できること
2. 日付または金額の**範囲指定**で検索できること
3. 2以上の任意の項目を**組み合わせて**検索できること

②と③は、税務調査の際に**ダウンロードの求めに応じられる**ようにしていれば不要です。しかし「求めに応じられるようにする」体制が整っているか自信がない場合、②③も満たしておくほうが安心です。

ここで差が出ます。

**ファイル名方式では、②と③は事実上できません。**
OSのファイル検索で「2026年1月から3月まで」の範囲指定はできません。「10万円以上」もできません。「A社かつ50万円以上」という組み合わせも無理です。

**索引簿方式なら、Excelのオートフィルタで全部できます。**
日付で範囲指定、金額で「〜以上」、取引先で絞り込み、しかも同時に。表計算ソフトが元々得意な操作です。

つまり索引簿は、**②③まで含めて満たせる方法**です。

### どちらを選ぶか

| | ファイル名方式 | 索引簿方式 |
|---|---|---|
| 初期の手間 | 1件ずつ改名。重い | 表を作る。まとめてやれる |
| 運用の手間 | ファイルを置くだけ | **表の更新を忘れると破綻する** |
| 範囲指定・組合せ検索 | できない | できる |
| ファイルを直接見たとき | 何の書類か分かる | 連番なので分からない |
| 向いている人 | 件数が少ない／担当者が1人 | 件数が多い／複数人で扱う |

**両方やる必要はありません。**どちらか一方で要件を満たせます。

## 索引簿に入れる項目

### 必須の3項目

- **取引年月日**
- **取引金額**
- **取引先**

法令上求められているのはこの3つです。

### 入れておくと実務が楽になる項目

- **連番** … ファイルとの紐づけの軸になります
- **ファイル名** … 実ファイルへの対応。連番と一致させます
- **書類種別** … 請求書／領収書／納品書。後から探すとき効きます
- **登録番号（インボイス番号）** … 適格請求書の確認に使えます
- **備考** … 訂正や補足の記録

### 書き方の注意

**日付は `YYYY-MM-DD` か `YYYY/MM/DD` で統一する。**
和暦のまま入れると並び替えも範囲指定もできません。Excelが日付として認識する形式にしてください。

**金額はカンマを入れず、数値として入れる。**
`1,234,567` と文字列で入れると、「10万円以上」の絞り込みができません。表示形式でカンマを付けるのは構いませんが、中身は数値にします。

**取引先の表記を統一する。**
`株式会社ABC` と `(株)ABC` が混在すると、検索しても全部は出てきません。ここが索引簿で最も壊れやすい箇所です。

## Excelで作る手順

### 1. 見出し行を作る

1行目にこう入れます。

```
連番	取引年月日	取引金額	取引先	書類種別	登録番号	ファイル名	備考
```

### 2. 「テーブル」にする

見出しを含めて範囲を選び、**挿入 → テーブル**（Ctrl+T）。

これをやっておくと、行を追加したときに自動で範囲が広がり、オートフィルタも最初から付きます。**この一手間で後が楽になります。**

### 3. 列の書式を決める

- 取引年月日 … 「日付」
- 取引金額 … 「数値」（桁区切りを使う場合は表示形式で）

### 4. 1件ずつ入力する

PDFを開いて3項目を読み、行を足していきます。

**金額は税込の合計を取ります。**請求書には複数の金額が並ぶので注意してください。

```
小計        1,122,334
消費税(10%)   112,233
合計        1,234,567   ← これを使う
```

**日付は「請求日」「発行日」を取ります。**「お支払期限」ではありません。

### 5. 保存する

CSVでもxlsxでも構いません。**保存先は、対象のファイルと同じ場所**にしてください。

## 索引簿だけでは足りないもの

ここを見落とす方が多いのですが、索引簿は**可視性の確保**（検索要件）に対応するものです。
電子帳簿保存法にはもう一つ、**真実性の確保**という要件があります。

タイムスタンプを使わない場合、**訂正削除の防止に関する事務処理規程**を定めて運用する方法が認められています。国税庁がサンプルを公開しているので、自社の実態に合わせて調整し、備え付けてください。

索引簿を作っても、この規程がないと対応としては不十分です。

---

## そもそも索引簿が不要な場合

次のいずれかに当てはまる場合、**検索要件そのものが不要**です。

- 基準期間（2課税年度前）の**売上高が5,000万円以下**で、ダウンロードの求めに応じられるようにしている
- 電子取引データを出力した書面を**日付および取引先ごとに整理**して提示・提出できるようにしており、かつダウンロードの求めに応じられるようにしている

該当する場合、索引簿を作る必要はありません。データを電子のまま保存し、事務処理規程を備え付けておけば足ります。

**まず自社が対象かどうかを確認してから作業を始めてください。**不要な作業を数日かけてしまう前に。

---

## まとめ

- 索引簿は**ファイル名方式の代わり**になる。どちらか一方でよい
- 索引簿なら**範囲指定検索・組合せ検索まで満たせる**
- 必須は**取引年月日・取引金額・取引先**の3項目
- **日付は日付形式、金額は数値**で入れる。文字列にすると検索が機能しない
- 弱点は**更新忘れ**。運用でカバーする必要がある
- あわせて**事務処理規程**を備え付ける

## 1件ずつ入力するのが大変な場合

索引簿の入力を自動化するツールを作りました。

請求書・領収書のPDFをまとめて読み込むと、取引年月日・取引金額・取引先を読み取り、**そのままExcelで開ける索引簿CSV**を書き出します。上に書いた項目（連番・書類種別・登録番号・ファイル名）も含めた形で出力されます。

**索引簿の作成は無料で、件数の制限もありません。**透かしや広告行も入らないので、そのまま実務で使えます。

読み込んだファイルは**外部に送信されません**。すべてブラウザの中だけで処理するので、請求書がどこかのサーバーに送られることはありません。通信を切った状態でも同じように動きます。

→ **[電帳法 索引簿・ファイル名 作成ツール（無料）](https://denchofiler.github.io/tool/)**

自動判定なので外すことはあります。確信度が低い箇所は色で示し、「1,234,567（ご請求金額）」「1,122,334（小計）」のように**根拠付きの候補**から選べるようにしてあります。最終確認は人が行う前提です。
