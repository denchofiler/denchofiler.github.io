メールで届いた請求書を、とりあえずフォルダに放り込んである。
ファイル名は `請求書.pdf`、`scan_0412.pdf`、`1月分ご請求(最終).pdf` のまま。

いつか整理しなければと思いながら、月が変わってまた溜まっていく。この記事は、その状態から抜け出すための手順です。

先に結論を書きます。**Windowsやmacの「一括リネーム」機能では、電子帳簿保存法の要件は満たせません。** 理由は後述します。ここを勘違いしたまま作業を始めると、丸一日かけて全部やり直すことになります。

---

## そもそも、ファイル名に何を入れる必要があるのか

電子帳簿保存法では、電子取引データについて**検索機能の確保**が求められています。具体的にはこの3つです。

1. **取引年月日・取引金額・取引先**で検索できること
2. 日付または金額の**範囲指定**で検索できること
3. 2以上の任意の項目を**組み合わせて**検索できること

このうち②と③は、税務調査の際に**ダウンロードの求めに応じられる**ようにしていれば不要です。

つまり多くの事業者にとって必要なのは、**①の3項目で検索できる状態**です。

そして国税庁は、①を満たす方法として次の2つを認めています。

- **ファイル名方式** — ファイル名に3項目を含める
- **索引簿方式** — 別途一覧表（索引簿）を作り、ファイルと紐づける

**どちらか一方でかまいません。** これは後半で効いてくるので覚えておいてください。

### その前に：そもそも対応が必要か確認する

次のいずれかに当てはまる場合、**検索要件そのものが不要**です。

- 基準期間（2課税年度前）の**売上高が5,000万円以下**で、ダウンロードの求めに応じられるようにしている
- 電子取引データを出力した書面を**日付および取引先ごとに整理**して提示・提出できるようにしており、かつダウンロードの求めに応じられるようにしている

売上5,000万円以下の事業者は、ここで読むのをやめても構いません。データを電子のまま保存し、事務処理規程を備え付けておけば足ります。

以下は、**検索要件への対応が必要な方**向けです。

---

## ファイル名の付け方

決まった書式は法律で定められていません。実務では次の形が広く使われています。

```
20260115_1234567_テスト工業株式会社.pdf
```

`日付_金額_取引先` の順です。

- **日付** … `YYYYMMDD` の8桁。ハイフンやスラッシュは使わない方が並び順が安定します
- **金額** … 税込の総額。カンマは入れない
- **取引先** … 発行元の名称。`株式会社` を `(株)` に略すかは、**社内で統一**してください

### 使えない文字に注意

次の文字はファイル名に使えません。取引先名に含まれる場合は削除するか置き換えます。

```
\ / : * ? " < > |
```

また、**表記ゆれが検索の敵**です。同じ取引先が `株式会社ABC` と `(株)ABC` と `ABC株式会社` で混在すると、検索しても全部は出てきません。担当者が複数いる場合は、ルールを文書にしておくことをおすすめします。

## ここが落とし穴：OSの一括リネームでは終わらない

「ファイルをまとめて選んで名前を変えればいい」と考えて、まずここを試す方が多いはずです。

**Windows のエクスプローラー**
複数選択して F2 を押すと、`請求書 (1).pdf`、`請求書 (2).pdf` のように連番で付け直せます。

**Mac の Finder**
複数選択して右クリック →「名前を変更」で、置換・フォーマット・テキスト追加ができます。

**PowerShell / バッチファイル**
パターンに沿った置換や連番付与を自動化できます。

これらはすべて**正しく動きます。が、電帳法の要件は満たせません。**

理由はシンプルです。

> **取引年月日・取引金額・取引先は、ファイルの「中身」にしか書かれていないからです。**

OSの一括リネーム機能は、ファイル名という「外側」しか扱えません。連番を振ることはできても、その請求書が「いつ・いくら・どこから」なのかは知りようがない。だから `請求書 (1).pdf` にはなっても、`20260115_1234567_テスト工業株式会社.pdf` にはならないのです。

結局、**1件ずつ開いて、3項目を読み取って、手で打ち込む**しかありません。

## 手作業でやる場合の現実的な手順

やると決めたなら、次の順序が最も速いです。

### 1. 年月フォルダを先に作る

```
2026/
 ├ 01/
 ├ 02/
 └ 03/
```

可視性の確保の観点でも、年月別の整理は実務で推奨されています。先にフォルダを作っておくと、後の作業が「開いて・名前を付けて・放り込む」の繰り返しになり、迷いが減ります。

### 2. プレビューを使って、開かずに読む

PDFを1件ずつアプリで開くと時間を食います。

- **Windows** … エクスプローラーの「プレビューウィンドウ」（表示タブ）を有効にする
- **Mac** … ファイルを選んでスペースキー（クイックルック）

一覧で矢印キーを押しながら中身を確認でき、体感で倍ほど速くなります。

### 3. 名前を打つときは日付から

`2026` まで打てば同じ月のファイルが候補に出るので、入力量が減ります。

### 4. 金額は「税込の合計」で統一する

ここが最も間違えやすい箇所です。請求書には複数の金額が並びます。

```
小計        1,122,334
消費税(10%)   112,233
合計        1,234,567   ← これを使う
```

`小計` や `消費税` を拾ってしまうと、金額での検索が機能しません。**「ご請求金額」「合計」「お支払金額」といったラベルが付いた、いちばん大きい額**が税込総額です。

継続取引の請求書では `前回請求額` や `繰越金額` が載っていることがあります。これらが最大額になっている場合もあるので、**ラベルを必ず確認**してください。

### 5. 日付は「請求日」を取る

`お支払期限` と取り違えないでください。取引年月日として使うのは、`請求日`・`発行日`・`取引年月日` などのラベルが付いた方です。

## 手作業がつらい場合の、もう一つの正解

ここで冒頭の話に戻ります。国税庁は**索引簿方式**も認めています。

つまり、**ファイル名は連番のままでいい**のです。

```
0001.pdf
0002.pdf
0003.pdf
```

そのうえで、Excelで次のような一覧を作ります。

| 連番 | 取引年月日 | 取引金額 | 取引先 | ファイル名 |
|---|---|---|---|---|
| 1 | 2026-01-15 | 1234567 | テスト工業株式会社 | 0001.pdf |
| 2 | 2026-02-03 | 330000 | 株式会社ブルーオーシャン | 0002.pdf |

これを同じフォルダに置いて保存すれば、検索要件を満たせます。

**この方式の利点は、範囲指定検索と組合せ検索がそのまま可能になること**です。Excelのオートフィルタを使えば「2026年1月〜3月で、10万円以上の、A社からの請求書」がすぐ絞り込めます。ファイル名方式では、これはできません。

**欠点は、索引簿の更新を忘れると破綻すること**です。ファイルを追加したら必ず行を足す運用が必要になります。

どちらが向いているかは、件数と体制次第です。

- **月の件数が少なく、担当者が1人** → ファイル名方式
- **件数が多い、または複数人が触る** → 索引簿方式

---

## 忘れられがちな「もう一つの要件」

検索要件（可視性の確保）ばかり注目されますが、**真実性の確保**も必要です。

タイムスタンプを使わない場合、**訂正削除の防止に関する事務処理規程**を定めて運用する方法が認められています。国税庁がサンプルを公開しており、自社の実態に合わせて調整して備え付けます。

ファイル名を整えても、この規程がないと対応としては不十分です。あわせて用意してください。

---

## まとめ

- OSの一括リネームでは要件を満たせない。**3項目はファイルの中身にしかない**から
- ファイル名方式と索引簿方式、**どちらか一方でよい**
- 金額は**税込総額**、日付は**請求日**。小計・消費税・支払期限と取り違えない
- 表記ゆれを防ぐため、社内のルールを文書にする
- **事務処理規程**もあわせて備え付ける

## 手で打つ件数が多い場合

ここまでの作業を、PDFを読み込んで自動化するツールを作りました。

取引年月日・取引金額・取引先を読み取って、ファイル名の案と**索引簿CSV**を作ります。索引簿の作成までは無料で、件数制限もありません。

読み込んだファイルは**外部に送信されません**。すべてブラウザの中だけで処理するので、請求書がどこかのサーバーに送られることはありません。通信を切った状態でも同じように動きます。

→ **[電帳法 ファイル名 変換ツール（無料）](https://9q6xtwz22p-cmd.github.io/dencho-filer/tool/)**

自動判定なので外すこともあります。確信度が低い箇所は色で示し、「20260115（請求日）」「20260228（支払期限）」のように**根拠付きの候補**から選べるようにしてあります。最終確認は人が行う前提で作りました。
