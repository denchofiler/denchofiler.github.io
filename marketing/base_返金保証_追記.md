# BASE に追記するもの（2箇所）

サイト側はすでに30日返金保証を掲載済み。**BASEが未対応だと記載が食い違うので、必ず揃えてください。**

---

## 1. 商品説明の「先頭」に追記

商品編集 → 商品説明 の**一番上**に貼る。下のほうに置くと読まれません。

```
──────────────────────────────
30日間の返金保証つき

お手元の請求書でお試しいただき、ご期待に沿わなければ、
購入日から30日以内にお問い合わせよりご連絡ください。
理由を問わず全額をご返金いたします。
ダウンロード済みでも構いません。

無名の売り手から9,800円をお支払いいただくわけですから、
そのリスクはこちらで負います。
──────────────────────────────

購入前に、無料版で読み取り精度をご確認いただけます。
索引簿CSVの作成までは無料・件数無制限・登録不要です。
https://denchofiler.github.io/tool/
```

---

## 2. 特定商取引法に関する表記を差し替え

設定 → 特定商取引法に関する表記 → **【返品・キャンセルについて】の項目だけ**を下に置き換える。

```
本商品はデジタルコンテンツですが、30日間の返金保証を設けています。
お手元の請求書でお試しいただき、ご期待に沿わなかった場合は、
購入日から30日以内にお問い合わせフォームよりご連絡ください。
理由を問わず、全額をご返金いたします。ダウンロード済みでも構いません。

なお、ご購入前に無料版で動作と読み取り結果をご確認いただけます。
無料版：https://denchofiler.github.io/tool/
```

---

## 守る義務が発生します

**返金請求が来たら、理由を問わず必ず返金してください。**
BASE の 注文管理 → 該当注文 → 返金 から操作できます。

デジタル商品で返金請求が来ることはまずありませんが、
書いた以上は守らないと、この分野で一番失ってはいけない信用が飛びます。

嫌ならサイト側の記載も外します。言ってください。
