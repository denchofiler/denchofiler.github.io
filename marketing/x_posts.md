## 考え方

**売り込みの投稿は伸びない。「やらなくていい」と言い切る投稿が伸びる。**

電帳法まわりは、ベンダーが「対応しないと大変です」と煽る情報で埋まっている。
そこに「その作業、たぶん不要です」と正確な情報を投げると、
経理担当と税理士に刺さって、保存とリポストが発生する。

売る話は6投稿に1回で足りる。**残りは全部、無料で役に立つ情報にする。**

順番も重要。**いきなり宣伝から始めない。**
2〜5を先に流して、反応が出てから1を投げる。

## 投稿1｜ツール公開（宣伝。最初には出さない）

```
請求書のPDFをまとめて放り込むと、取引年月日・取引金額・取引先を読み取って、
電帳法の検索要件を満たすファイル名と索引簿CSVを作るツールを公開しました。

・無料
・登録不要
・ファイルは外部に送信されません（通信を切っても動きます）

https://denchofiler.github.io/tool/
```

**「外部に送信されない」が一番効く行です。** クラウド会計が絶対に言えない一行なので、必ず残す。

---

## 投稿2｜検索要件は不要かもしれない（最初に投げる）

```
電帳法で一番よくある誤解。

「検索要件に対応しないといけない」

基準期間の売上高が5,000万円以下なら、対応は不要です。
基準期間は今期ではなく2課税年度前。2026年なら2024年の数字を見ます。

ファイル名を1件ずつ直す作業、始める前に確認してください。
```

## 投稿3｜紙はスキャンしなくていい

```
紙で受け取った領収書、スキャンしなくていいです。

スキャナ保存は「任意」。義務ではありません。

義務なのは、電子で受け取ったものを電子のまま保存するほう。
メール添付のPDFを印刷して原本を捨てる、これがNGです。

ここを逆に理解している人がかなり多い。
```

---

## 投稿4｜システムは要らない

```
「電帳法対応にはシステムを入れないといけない」は誤解です。

真実性の確保は、タイムスタンプの代わりに
「訂正削除の防止に関する事務処理規程」を備え付ける方法が認められています。

国税庁がサンプルを公開していて、費用は0円。紙1枚を作って置くだけです。
```

---

## 投稿5｜インボイスとの切り分け

```
インボイスの登録番号、ファイル名に入れる必要ありません。

電帳法の検索要件は
・取引年月日
・取引金額
・取引先
の3項目だけ。登録番号は入っていません。

持ちたいなら索引簿の列にするほうが、免税事業者の抽出に使えて後で効きます。
```

## 投稿6｜稟議（買う人に届く投稿）

```
電帳法の対応が社内で通らない理由、だいたいこの3つ。

・罰則が条文に無いのでインパクトが伝わらない
・売上に直結しないので効果を数字で書けない
・義務化から2年経っていて「今まで平気だったよね」と言われる

月100件を超えているなら、法令の話ではなく工数の話で書くと通ります。
```

**この投稿に反応した人が、唯一の買い手候補です。** いいねした人は見ておく。

---

## 投稿7｜税理士向け（拡散の起点になりうる）

```
顧問先から電帳法を聞かれたときの仕分け、3問で終わります。

1. 電子で受け取った証憑があるか → ほぼ全社ある
2. 基準期間の売上が5,000万円超か → 超えなければ検索要件は不要
3. 事務処理規程を備え付けているか → 無ければ国税庁のサンプルで0円

大半の顧問先は1と3だけで終わります。
```

**税理士1人の後ろに顧問先が数十社います。** ここが一番効率が高い。

## 投稿より効く行動

小さいアカウントの投稿は、そのままではほぼ誰にも見られません。
**リーチは投稿ではなくリプライから作ります。**

- 「電帳法」「電子帳簿保存法」「インボイス」で検索して、**困っている投稿に正確な答えを返す**
- 売り込まない。URLも貼らない。**答えだけ返す**
- プロフィールにツールのURLを1本だけ置く

これを1日3件、2週間続けるほうが、投稿を10本出すより効きます。
理由は、困っている人のツイートには**同じ悩みの人が集まっている**から。

## やらないこと

- **フォロワーを買わない。** 経理クラスタは見る人が見れば分かる
- **相互フォロー企画に入らない。** 買わない人が集まるだけ
- **煽らない。**「対応しないと罰金」は嘘なので絶対に書かない。この分野は嘘が一番早くバレる
