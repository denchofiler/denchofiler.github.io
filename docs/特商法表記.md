# 特定商取引法に基づく表記（下書き）

BASEの「設定 → 特定商取引法に関する表記」にそのまま貼れる形にしてあります。
**`____` の部分はあなたしか埋められません。**

> 個人で販売する場合、原則として**氏名・住所・電話番号**の記載が必要です。
> BASEには「請求があった場合に遅滞なく開示する」旨を記載して省略できる仕組みがあります。
> 省略する場合も、**請求があれば必ず開示する義務**が残ります。運用できる形を選んでください。

## 記入時の注意

| 項目 | 気をつけること |
|---|---|
| 所在地・電話番号 | 自宅住所を出したくない場合は「請求があれば開示」方式。ただし請求時は本当に開示する必要があります |
| メールアドレス | **必ず届くものを。** 問い合わせ対応が信用に直結します。専用のフリーメールで構いません |
| 返品条件 | デジタル商品は返品不可が一般的ですが、**「無料版で事前に確認できる」ことを明記**しておくと、トラブルの予防になります |
| 屋号 | 開業届を出していなくても、屋号での販売自体は可能です。迷ったら氏名で始めて構いません |

## 開業届・確定申告について

- 販売を継続的に行う場合、**事業所得**として確定申告が必要になる可能性があります
- 給与所得者の副業の場合、**年間20万円を超える所得**で確定申告が必要になるのが一般的な目安です
- 具体的な判断は税務署または税理士にご確認ください

> 私は税務の助言はできません。上は一般的に言われている目安で、あなたの状況に当てはまるかは別です。
> 売上が立ち始めたら、早めに確認しておくことをおすすめします。
