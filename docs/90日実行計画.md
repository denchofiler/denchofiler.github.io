# 売れ始めたら

1. **購入者に必ず聞く：** 「読み取りが外れた請求書はありましたか」
   → **その実物が、この商品で最も価値のあるフィードバックです。**
   `src/parser.js` のキーワード辞書に追記すれば精度が上がります。私に渡してください。
2. **月商5万円を超えたら：** Stripe直販への移行を検討（手数料 6.6% → 3.6%）
3. **会計事務所から問い合わせが来たら：** 最優先で対応する。顧問先へ横展開される可能性があります
