## セッション1｜サイトを公開する　✅ 完了

`https://9q6xtwz22p-cmd.github.io/dencho-filer/` で公開済みです。動作確認も取れています。

- 販売ページ　https://9q6xtwz22p-cmd.github.io/dencho-filer/

> `site/` の中身だけを `gh-pages` ブランチのルートへ送る形にしてあります。

**以降、サイトを更新するときはこの1コマンドです。**

```bash
cd ~/AI自動ビジネス && npm run deploy
```

## セッション2｜Google Search Console に登録する　✅ 完了

- 所有権の確認：完了（HTMLタグ方式）
- サイトマップ送信：完了（`sitemap.xml`）

確認タグは `site.config.json` に保存してあるので、`npm run deploy` しても消えません。

> つまずいた点の記録：
> - サイトマップの入力欄は**先頭スラッシュ不要**。`sitemap.xml` と入れる（`/sitemap.xml` だと取得に失敗する）
> - 所有権確認は、タグをサイトに反映してから「確認」を押す。押す順番を逆にすると必ず失敗する

## セッション3｜BASE を開設する（30分）

1. https://thebase.com/ で「ショップを開設する」
2. メールアドレスとパスワードを登録（**パスワードの入力はあなたの作業です。私は行いません**）
3. ショップURLを決める（例：`denchofiler.base.shop`）
4. 「Apps」→ **「デジタルコンテンツ販売」** をインストール
5. 「設定」→「特定商取引法に関する表記」を入力（`docs/特商法表記.md` に下書きがあります）
6. 「設定」→「お金を受け取る」→ 本人確認と振込口座の登録を申請

> 本人確認は数日かかることがあります。**先に申請だけ出しておく**のが要点です。
> 商品の登録は審査を待たずに進められます。

## セッション4｜納品用ZIPを作って商品を登録する（30分）

```bash

```

`電帳ファイラー_製品版.zip`（約790KB）ができます。

> `zip` コマンドは使わないでください。macOSの `zip` は日本語ファイル名にUTF-8フラグを立てないため、

3. 商品名・説明文：`marketing/販売文.md` からそのまま貼り付け
4. 価格：**9800**
5. 商品画像：`marketing/商品画像_hero.jpg` と `lp/assets/screen-table.jpg`
6. 在庫数：**必須項目です。** 999 など大きい数を入れてください
7. 公開

同じ手順で「会計事務所ライセンス」を **39800** で登録します（同じZIPで構いません）。

# 売れ始めたら

1. **購入者に必ず聞く：** 「読み取りが外れた請求書はありましたか」
   → **その実物が、この商品で最も価値のあるフィードバックです。**
   `src/parser.js` のキーワード辞書に追記すれば精度が上がります。私に渡してください。
2. **月商5万円を超えたら：** Stripe直販への移行を検討（手数料 6.6% → 3.6%）
3. **会計事務所から問い合わせが来たら：** 最優先で対応する。顧問先へ横展開される可能性があります

# 迷ったときの原則

- **値下げを最初の手にしない。** 伝え方を直すのが先
- **無料版を弱くしない。** 無料版が役に立つことが集客の前提
- **精度を誇張しない。** 会計証憑を扱う商品は、正直さが商品性そのもの
- **止まらない。** 週1回でも続けるほうが、まとめて頑張って止まるより強い
