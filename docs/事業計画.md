# 電帳ファイラー 事業計画

作成 2026-09-11 ／ 前提：**元手0円・販売のツテなし・まとまった作業時間が取れない**

---

## 0. この計画の前提を先に書く

あなたの条件は「ツテなし・時間なし・元手なし」です。この条件で成立する戦略は、実は多くありません。

**成立しないもの（やらない理由つき）**

| やらないこと | 理由 |
|---|---|
| ゼロフォロワーでのX発信を主軸にする | 初期のオーガニック到達はほぼ0。1投稿の期待値が低すぎて、時間対効果が最悪 |
| 税理士への一斉営業 | ツテが無い状態での新規開拓は1件あたりの時間が重い。時間が取れない前提と噛み合わない |
| 広告出稿 | 元手0円のため不可 |
| 毎日の発信 | 継続できない計画は計画ではない |

**成立するもの**

> **検索から来る人を、無料ツールで受け止める。**

理由は3つです。

1. **作り置きが効く。** 一度書いた記事とツールは、寝ている間も働き続けます。時間が取れない人向けの唯一の資産形成です。
2. **電帳法は「困って検索する」課題。** 能動的に探している人が毎日います。こちらから探しに行く必要がありません。
3. **競合が席を空けている。** 後述します。

**ただし、正直に言います。検索流入は即効性がありません。**
新規ドメインがインデックスされ、ロングテールで拾われ始めるまで**最短で2〜3ヶ月**かかります。
この計画での**初売上の現実的な着地は3〜6ヶ月目**です。今月中に売れる計画ではありません。
「0円・ツテなし・時間なし」で今月中に売る方法は、私が知る限りありません。あると言う人は疑ってください。

## 1. 市場で空いている席

「電子帳簿保存法 ファイル名 付け方」で検索すると、上位はこうなっています。

| 順位帯 | サイト | 記事の結論 |
|---|---|---|
| 上位 | freee / マネーフォワード / 弥生 | 「システム導入をご検討ください」（自社SaaS） |
| 上位 | TOKIUM / WingArc / GMOサイン | 同上 |
| 上位 | NTT東日本 / Fleekdrive | 同上 |

**全社が「ルールの説明」で終わり、最後は自社SaaSへ誘導しています。
その場で問題を解決する道具を出しているところが、1つもありません。**

読者の状態はこうです。

> ルールは分かった。で、この溜まった100件のPDFはどうすればいいのか。

ここに、**その場で使える無料ツール**を置く。これが空いている席です。

### 勝てない戦い／勝てる戦い

- **勝てない**：「電子帳簿保存法とは」のような大きな情報キーワード。ドメインの力で負けます。
- **勝てる**：「ファイル名 一括変更 ツール」「索引簿 自動作成」のような**道具を探している検索**。
  情報記事を量産するSaaS各社は、ここに実物を置いていません。

## 2. 商品と価格

| プラン | 価格（税込） | 内容 |
|---|---|---|
| 無料版（Webツール） | ¥0 | 読み取り・リネーム案の表示・**索引簿CSVの作成（件数無制限）** |
| 1事業者ライセンス | **¥9,800** | 上記＋**ファイル名の一括変更とZIP書き出し**、オフライン版HTML、事務処理規程ひな形 |
| 会計事務所ライセンス | **¥39,800** | 上記＋顧問先での利用を含む（顧問先数の制限なし） |

### 無料と有料の線を、ここに引いた理由

国税庁は検索要件を満たす方法として、**ファイル名方式**と**索引簿方式**の両方を認めています。

- **無料版＝索引簿方式で完結できる。** 本当に無料で問題が解決します。だから使われ、共有され、リンクされます。
- **有料版＝ファイルそのものを整える。** 月100件を手で保存し直すのは現実的でないので、ここにお金が発生します。

無料版を「機能制限で使い物にならない体験版」にすると、集客装置になりません。
**無料版が本当に役に立つことが、この戦略の前提条件です。**

### 手取り額（BASE スタンダードプランの場合）

手数料は 決済3.6% + サービス利用料3.0% + 40円/注文、振込手数料250円。

| 販売価格 | 手数料 | 手取り |
|---:|---:|---:|
| ¥9,800 | ¥687 | **¥9,113** |
| ¥39,800 | ¥2,667 | **¥37,133** |

| 月の目標 | 必要な販売数 |
|---|---|
| 月 ¥10,000 | 1事業者版 2件 |
| 月 ¥50,000 | 1事業者版 6件、または事務所版 2件 |

**事務所版1件＝1事業者版4件。** 会計事務所に届いたときの効率が突出しています。
ただし今はツテが無いので、**まず検索で認知を作り、事務所から見つけてもらう**順番にします。

## 3. 決済方式の決定：BASE 一本

ご依頼どおり私が決めます。**BASE でダウンロード販売**を推奨します。

| | BASE | Stripe |
|---|---|---|
| 開始まで | 実質即日 | 審査に数日 |
| 手数料 | 6.6%＋40円 | 3.6% |
| 必要な作業 | 管理画面で商品登録するだけ | 決済リンク作成＋LPへの組み込み＋納品メールの仕組み |
| 特商法表記 | 入力フォームあり | 自前で用意 |
| 納品 | ダウンロード販売機能が標準 | 自前で仕組みを作る |

**判断の根拠：手数料差より、あなたの時間のほうが高い。**

¥9,800 の手数料差は1件あたり約294円です。月10件売れても差は月2,940円。
一方 Stripe は納品の仕組みを自作する必要があり、時間が取れない前提と噛み合いません。

> **月商5万円を超えたら Stripe への移行を検討してください。** そのとき初めて手数料差が意味を持ちます。

**委託販売NGのご指定について：** BASEは**あなたが販売者**となる自社通販の作成サービスで、他者に販売を代行させる委託販売ではありません。
それでもプラットフォーム経由が気になる場合は、Stripeのみで進めることも可能です。その場合は納品の仕組みを別途作ります。

```

   ↓
```

**無料ツールを入口にします。** 会計証憑を扱う商品は、触ってもらう以外に信用を得る方法がありません。

### 置き場所（すべて0円）

| 用途 | 置き場所 | 理由 |
|---|---|---|

## 5. コンテンツ計画（これが本体）

書く記事は**「ルールの解説」ではありません。**そこはSaaS各社が押さえています。
狙うのは**「で、どうやるの」**の検索です。

| # | 記事 | 狙う検索意図 | ツールへの繋げ方 |
|---|---|---|---|
| 1 | 電帳法のファイル名を一括で変える方法（ソフト導入なし） | 一括変更 ツール | 記事＝ツールの使い方そのもの |
| 2 | 索引簿の作り方とテンプレート｜Excelで作る手順と自動で作る方法 | 索引簿 テンプレート | 手作業の手順を先に示し、最後に自動化 |
| 3 | 売上5,000万円以下なら検索要件は不要。自社が対象か判定する | 検索要件 不要 条件 | 対象だった人だけツールへ |
| 4 | 訂正削除の防止に関する事務処理規程｜ひな形と書き方 | 事務処理規程 ひな形 | ひな形を無料配布 |
| 5 | 和暦で書かれた請求書の保存はどうするか | 和暦 電帳法 | 和暦対応は実装済み |
| 6 | スキャンした画像PDFは検索要件を満たせるか | 画像PDF 電帳法 | 限界を正直に書く＝信用になる |
| 7 | 請求書のファイル名に使えない文字と、表記ゆれの防ぎ方 | ファイル名 記号 | 表記ゆれはツールが吸収 |
| 8 | 電帳法対応で会計ソフトを乗り換えなくていい理由 | 電帳法 会計ソフト 変更 | 乗り換え不要が差別化 |

**記事の書き方の原則：最後までツールの話をしない。**
読者の問題を記事内で解決しきり、末尾に「手作業が大変なら、これを使ってください」と置く。
売り込み記事は読まれず、リンクもされません。

## 6. 指標と判断ゲート

数字を見る場所は **Google Search Console**（無料）と **BASEの管理画面**の2つだけにします。

| 節目 | 見る数字 | 合格ライン | 下回ったときにやること |
|---|---|---|---|
| 30日 | Search Console の登録・インデックス | 2ページとも登録済み | サイトマップ再送信、robots.txt確認 |
| 60日 | 検索の表示回数 | 月100回以上 | 記事の狙う検索語を、より具体的なものへ変更 |
| 90日 | ツールの利用 | 月30回以上 | 記事の本数不足。まず本数を積む |
| 120日 | 売上 | 1件以上 | **値下げはしない。**購入ボタンの位置と、有料版の価値の伝え方を直す |
| 180日 | 売上 | 月2件以上 | ここで0なら、ターゲットを会計事務所に絞り直す |

> **値下げを最初の打ち手にしないでください。** ¥9,800 が高くて売れないのではなく、
> 「有料版で何が解決するか」が伝わっていない場合がほとんどです。
> 価格を下げると、次に下げる場所が無くなります。

## 7. リスクと対処

| リスク | 中身 | 対処 |
|---|---|---|
| **検索順位が上がらない** | 最大のリスク。SaaS各社のドメインは強い | 情報キーワードで正面から戦わない。ツール検索と長尾に限定する。Vector登録で被リンクを得る |
| **無料版で満足されて売れない** | 索引簿方式で完結する人は買わない | それは織り込み済み。**その人たちが記事を共有し、次の人を連れてくる**。有料の相手は件数が多い事業者 |
| **読み取り精度への苦情** | 請求書の書式は無限にある | 「自動判定を信用しすぎない設計」を前面に出してある。外した実物の請求書は改善材料として最重要 |
| **法改正** | 要件が変わる可能性 | 索引簿とファイル名という土台は当面変わらない。変更時は記事の更新が必要 |
| **続かない** | 時間が取れない前提での最大の敵 | 1回30分の単位に割った実行計画（`docs/90日実行計画.md`）に落としてある |
