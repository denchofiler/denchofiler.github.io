# 起動手順 — あなたにしかできない作業

製品・販売ページ・販売文はすべて完成しています。
ここに残っているのは、**私（AI）が代行してはいけない、またはできない作業**だけです。

理由も添えてあります。

---

## なぜ私がここで止まるのか

| できないこと | 理由 |
|---|---|
| アカウント開設・パスワード入力 | 本人確認と契約行為にあたるため、私は行いません |
| 銀行口座・本人確認書類の登録 | 同上。金融情報の入力は私の禁止事項です |
| 公開・出品（外部への発信） | あなたの名前で世に出るものなので、あなたの承認が必要です |
| SNS投稿・メール送信 | 同上 |

つまり残作業は「**あなたが本人として名乗る**」部分だけです。

---

## 手順

### ステップ1 — 体験版を公開する（5分）

体験版はすでに公開URLになっていますが、**現在は非公開（あなただけが見える状態）**です。

1. 下記URLを開く
   https://claude.ai/code/artifact/e3537777-bee1-41ce-8333-4e001b4b0698
2. ページの共有メニューから**共有を有効にする**
3. 販売ページと告知文の「体験版URL」欄に、このURLを記入する

販売ページ（LP）も同様です。
https://claude.ai/code/artifact/23c94998-6cf8-4269-9855-1b0803f7cc1d

> この2つは費用0円のまま、実在するURLとして使えます。
> 独自ドメインが欲しくなったら後から移せます。

---

### ステップ2 — 納品用ZIPを作る（1分）

```bash
cd ~/AI自動ビジネス && python3 tools/make_release.py
```

`電帳ファイラー_製品版.zip`（約790KB / 9ファイル）ができます。これをそのまま出品用にアップロードしてください。

> macOS の `zip` コマンドは日本語ファイル名にUTF-8フラグを立てないため、
> Windowsの購入者側で文字化けします。上のスクリプトはフラグを立てたうえで、
> 作成後に検証まで行います。`zip` コマンドは使わないでください。

---

### ステップ3 — 販売先を開設する

**方式A：即日始める場合（推奨）**

- [BASE](https://thebase.com/) または [BOOTH](https://booth.pm/)
- 開設費・月額0円、デジタル商品のダウンロード販売に対応
- 手数料：BASE 約6.6%+40円 / BOOTH 5.6%+22円

**方式B：手数料を抑える場合**

- [Stripe](https://stripe.com/jp) の Payment Links
- 手数料3.6%。審査に数日かかるため、方式Aと並行して準備するのが現実的

> **「第三者への委託販売系はNG」のご指定について**
> 方式A・Bはいずれも**あなたが販売者**となる直販で、他者に販売を代行させるものではありません。
> ただしプラットフォームを経由する点が気になる場合は、**方式Bだけ**で進めてください。
> その場合は販売ページ（LP）をそのまま使い、購入ボタンにStripeのリンクを差すだけで完結します。

登録時に必要なもの（あなたが入力してください）:
- 本人確認書類
- 振込先口座
- 特定商取引法に基づく表記（氏名・住所・連絡先・返品条件など）

---

### ステップ4 — 出品する

`marketing/販売文.md` の内容をそのまま貼り付けられます。

- 商品名、説明文（長文・短文）、価格表記をすべて用意済み
- 商品画像は `marketing/商品画像_hero.jpg` を使ってください（あなたが作成した図版）
- 2枚目以降には、実際に変換した画面のスクリーンショットを添えると効果的です

価格:
- 1事業者ライセンス ¥9,800
- 会計事務所ライセンス ¥39,800

---

### ステップ5 — 告知する

`marketing/告知案.md` に下書きがあります。

推奨する順番:
1. X で案A（痛みから入る投稿）
2. note で実務記事を1本
3. 接点のある税理士・会計事務所へ個別に案内

> ⚠️ 一斉送信や無差別DMは避けてください。特定電子メール法の問題に加えて、
> 会計証憑を扱う商品は信用が命です。送り方そのものが評価になります。

## 販売開始後に見るべきこと

| 指標 | 見方 |
|---|---|
| 体験版の起動数 | 告知が届いているか |
| 体験版 → 購入の転換 | 製品の説得力が足りているか |
| 問い合わせの内容 | 読み取りが外れた請求書の書式は、改善の最優先材料です |

**読み取りが外れた実物の請求書が、この製品で最も価値のあるフィードバックです。**
`src/parser.js` のキーワード辞書に追記すれば精度が上がります。
そういう報告が来たら、そのまま私に渡してください。
